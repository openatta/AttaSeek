# Artifact Pane 多 Pane Tab 系统 需求规格

> **创建日期：** 2026-06-10
> **状态：** 草稿
> **参考：** Codex Desktop（OpenAI）Artifact Pane 布局，VS Code Explorer/Editor/Terminal UX

---

## 1. 概述

### 1.1 目标

将 Artifact Pane（AP）重构为 **4 个独立 Pane + 统一 Tab 容器** 的面板系统。4 个 Pane——**浏览器 / 终端 / 文件 / 审查**——各自独立实现，通过 AP 标题栏的 Tab 系统自由组合。对齐 Codex Desktop 的 AP 交互模式。

### 1.2 背景

当前 AP 面板功能有限。用户需要一个统一的底部面板，可以同时持有浏览器、终端、文件资源管理器和 Git 审查视图，以 Tab 方式自由切换和组合。

### 1.3 用户角色

| 角色 | 说明 |
|------|------|
| 开发者 | AI 辅助开发，浏览项目文件、预览产物、使用终端、审查 Git 变更 |
| 普通用户 | 查看 agent 产出内容（代码/MD/图片/PDF），使用浏览器/终端 |

---

## 2. 核心设计原则

1. **4 个 Pane 各自独立实现** — 浏览器 / 终端 / 文件 / 审查 是 4 个独立组件，彼此不依赖，通过 AP Tab 容器组合
2. **Tab 是组合手段** — AP 标题栏的 Tab 系统是连接各 Pane 的唯一方式；每个 Tab 对应一个 Pane 实例
3. **上下文决定可用 Pane** — CHATS 状态仅浏览器+终端可用；项目状态 4 个全可用
4. **项目系统是文件/审查的门控** — 项目系统未就绪时文件 Pane 和审查 Pane 不出现在任何入口
5. **单/多实例约束** — 浏览器仅 1 个实例，终端/文件/审查允许多实例

## 3. 功能范围

### 3.1 In Scope（本次做）

#### AP 标题栏 & Tab 系统

- [ ] **Tab 栏** — AP 标题栏左侧显示已打开 Pane 的 Tab 列表，排布：`[Tab1] [Tab2] … [+] [<] [>]`
- [ ] **Tab 外观** — 每个 Tab 左侧显示 Pane 类型图标 + 名称；hover 时显示关闭 × 按钮
- [ ] **添加按钮 [+]** — 固定位于 Tab 列表右侧、滚动按钮左侧；点击弹出 Pane 选择菜单（可用项由当前上下文 + 单实例约束决定）
- [ ] **Tab 溢出滚动** — Tab 过多时显示 [<] [>] 滚动按钮
- [ ] **Tab 激活切换** — 点击 Tab 切换到对应 Pane
- [ ] **Tab 关闭** — 点击 × 关闭 Tab 及对应 Pane 实例
- [ ] **标题栏右侧按键区** — 保持现有 2 个按键不变：
  - **放大/缩小 toggle** — 单按键双态：AP 正常尺寸时显示放大图标，点击最大化；最大化时显示缩小图标，点击恢复原尺寸
  - **显示/隐藏 AP toggle** — 单按键双态，复用现有图标（非 ×）；AP 可见时隐藏，隐藏时重新显示

#### 空闲状态大按钮

- [ ] **CHATS 状态** — 无打开 Tab 时，AP 区居中显示 2 个大按钮（64×64 图标 + 文字标签）：**浏览器**、**终端**
- [ ] **项目状态** — 无打开 Tab 时，AP 区居中显示 4 个大按钮（64×64 图标 + 文字标签）：**浏览器**、**终端**、**文件**、**审查**
- [ ] **点击大按钮** — 创建对应 Pane 实例并以 Tab 形式加入 AP
- [ ] **文件/审查的门控** — 项目系统未就绪时，即使用户切换到"项目视图"，文件、审查大按钮也不出现

#### Pane 1：浏览器（Browser）

- [ ] **内嵌 Web 浏览器** — 基于 Electron `<webview>` 标签，沙盒隔离
- [ ] **单实例** — 全局仅 1 个浏览器 Pane；已存在时 [+] 菜单不显示"浏览器"选项
- [ ] **导航栏**（位于 AP 标题栏下方、浏览器内容上方）：
  - 左侧：[←] 后退 [→] 前进 [↻] 刷新
  - 中间：URL 输入框（可编辑）
  - 右侧：[⋮] 竖排三点菜单，点击展开下拉：
    - 强制重新加载
    - 显示设备工具栏（toggle）
    - ── 分隔线 ──
    - 缩放（默认 100%，可手动输入调整）
    - ── 分隔线 ──
    - 清除 Cookie
    - 清除缓存
- [ ] **设备工具栏** — Chrome DevTools 级设备模拟：设备预设列表（iPhone/iPad/Pixel 等）、UA 切换、视口尺寸自定义、触控模拟、DPR 调整、旋转

#### Pane 2：终端（Terminal）

- [ ] **内嵌终端** — 基于 xterm.js
- [ ] **多实例** — 允许多个终端 Tab 同时存在
- [ ] **默认工作目录** — CHATS 状态为用户 Home 目录（`~`）；项目状态为项目根目录
- [ ] **无额外标题栏** — 仅终端内容区，无独立导航/子标题栏

#### Pane 3：文件（File）

- [ ] **门控规则** — 仅在项目系统就绪 + 用户已打开项目时可用
- [ ] **布局** — 左预览区 + 右 File Explorer（可 toggle 隐藏）
- [ ] **副标题栏**（位于 AP 标题栏下方）：
  - 左侧：根目录路径（纯文本显示，不可编辑）
  - 右侧：Explorer 显示/隐藏 toggle 按钮
- [ ] **多实例** — 可打开多个文件 Pane（各自独立根目录和内部文件 Tab 集）
- [ ] **预览区内部 Tab** — 预览区内可打开多个文件，以内部 Tab 管理（Pane 内二级 Tab，非 AP 标题栏级）：
  - 左侧文件类型图标 + 文件名
  - hover 显示关闭 ×
  - Tab 溢出时左右滚动
- [ ] **File Explorer（右边栏）** — VS Code 对齐：
  - 树形展开/折叠目录
  - 文件/文件夹类型图标
  - 右键菜单：新建文件/文件夹、删除、重命名、复制路径
  - 当前预览文件自动在树中定位高亮
- [ ] **文本文件预览** — 语法加亮（TypeScript/JavaScript/JSON/Markdown/Python/Rust 至少 6 种）
- [ ] **Markdown 预览** — 源码高亮 + 渲染预览可切换
- [ ] **PDF 预览** — 内联 PDF 查看器，支持滚动翻页
- [ ] **图片预览** — PNG/JPG/GIF/SVG/WebP 内联显示，支持缩放自适应
- [ ] **内容双入口** — ① Explorer 点击打开 ② 左侧会话 agent Artifact 点击在预览区打开

#### Pane 4：审查（Review）

- [ ] **门控规则** — 仅在项目系统就绪 + 用户已打开项目 + 项目是 Git 仓库时完全可用
- [ ] **Git 查看器** — 对齐 Codex Desktop 的 Review Pane
- [ ] **副标题栏**（位于 AP 标题栏下方，Codex 对齐）：
  - **左侧**：
    - 分支选择器（下拉菜单列出本地分支，当前分支高亮）
  - **中间**：
    - Diff 范围选择器（3 项下拉）：**未提交变更**（默认）/ **全部分支变更**（vs base branch）/ **上轮变更**（最近一次 agent turn）
  - **右侧**：
    - Staged / Unstaged 切换（双态 toggle）
    - Stage All 按钮
    - Revert All 按钮
- [ ] **内容区**：
  - **变更文件列表** — 每个文件显示文件名 + 变更统计（+N −M 行）；可展开/折叠查看该文件的 diff
  - **Diff 视图** — inline 或 side-by-side 可切换（副标题栏提供切换入口）；语法高亮
  - **逐块操作** — 每个 diff hunk 可单独 Stage / Unstage / Revert
  - **内联评论** — hover 代码行时出现 [+] 按钮，点击添加评论
- [ ] **Commit 功能** — 副标题栏或内容区顶部有 commit 消息输入框 + Commit 按钮
- [ ] **Commit 历史** — 可查看项目 commit 历史列表：每条显示 SHA（短）、消息摘要、作者、时间；点击展开查看完整 diff
- [ ] **多实例** — 允许多个审查 Pane
- [ ] **非 Git 目录** — 当前项目不是 Git 仓库时，显示引导提示"初始化 Git 仓库"

### 3.2 Out of Scope（本次不做）

- 项目系统（"打开项目/工作区"概念）— 文件/审查 Pane 的门控逻辑预留，但项目系统本身不在本需求范围内
- File Explorer 拖拽移动文件
- File Explorer 文件名搜索过滤输入框
- 编辑器编辑/保存功能 — 预览区只读
- Git 远程操作（push/pull/fetch）— 仅本地 diff + commit
- PR 审查集成（`gh` CLI 联动）— 后续特性
- Tab 拖拽排序（AP 标题栏级 Tab 和预览区内部 Tab 均不做）
- 预览区拆分视图（Split View）
- 浏览器多 Tab（浏览器 Pane 自身内部的 Tab）

### 3.3 依赖

| 依赖项 | 类型 | 状态 |
|--------|------|------|
| Monaco Editor（语法加亮） | 内部 | 已集成 |
| xterm.js（终端） | 内部 | 已集成 |
| Electron `<webview>`（浏览器 Pane） | 平台 | Electron 原生支持 |
| Chrome DevTools 协议（设备工具栏） | 平台 | Electron 内置 |
| 文件系统 IPC | 内部 | 待确认现有能力 |
| Git CLI（审查 Pane 读取 diff/commit 历史） | 外部 | 用户机器需安装 git |
| 项目状态标记 | 内部 | 待实现（文件/审查的门控依赖） |

## 4. 用户场景

### 4.1 场景 1：CHATS 空闲 → 打开终端

- **给定** 用户在 CHATS 状态，AP 无任何 Tab
- **当** AP 区居中显示 2 个大按钮（浏览器 64×64 / 终端 64×64）
- **则** 用户点击"终端"→ AP 标题栏出现 `[>_ Terminal]` Tab，内容区显示终端（工作目录 ~）

### 4.2 场景 2：CHATS → 再打开浏览器

- **给定** 已有 1 个终端 Tab
- **当** 用户点击标题栏 [+] 按钮
- **则** 弹出菜单显示"浏览器"和"终端"两个选项；用户点击"浏览器"→ 新增 `[🌐 Browser]` Tab 并激活，显示导航栏 + 浏览器内容

### 4.3 场景 3：浏览器单实例约束

- **给定** 已有 1 个浏览器 Tab 和 1 个终端 Tab
- **当** 用户点击 [+]
- **则** 弹出菜单仅显示"终端"（浏览器已存在，不在菜单中）

### 4.4 场景 4：项目状态 → 打开文件 Pane

- **给定** 用户在项目状态（已打开项目），AP 无 Tab
- **当** AP 显示 4 个大按钮（浏览器/终端/文件/审查）
- **则** 用户点击"文件"→ 新增文件 Tab，显示副标题栏（项目根路径 + Explorer toggle）+ 预览区 + Explorer

### 4.5 场景 5：文件 Pane — Explorer 浏览 + 打开文件

- **给定** 文件 Pane 已打开，右边栏显示项目根目录树
- **当** 用户展开 `src/` → 点击 `App.tsx`
- **则** 预览区新增内部 Tab `[TS App.tsx]`，内容显示语法高亮的 TypeScript 代码

### 4.6 场景 6：文件 Pane — Explorer toggle

- **给定** 文件 Pane 显示左预览区 + 右 Explorer
- **当** 用户点击副标题栏右侧 toggle 按钮
- **则** Explorer 隐藏，预览区全宽；再次点击恢复

### 4.7 场景 7：文件 Pane — 从 agent Artifact 打开

- **给定** 左侧会话中 agent 产出了一个 Markdown 文档
- **当** 用户点击 Artifact 的"在预览区打开"
- **则** 如果已有文件 Pane→在该 Pane 预览区新建 Tab 显示；如果没有文件 Pane→自动新建文件 Pane 并打开

### 4.8 场景 8：文件 Pane — 预览内容类型

- **当** 打开 `.png` 文件 → 预览区显示图片，支持缩放
- **当** 打开 `.pdf` 文件 → 预览区显示 PDF 查看器，支持滚动翻页
- **当** 打开 `.md` 文件 → 预览区默认渲染预览，可切换到源码高亮视图
- **当** 打开未知二进制文件 → 显示"不支持预览此文件类型"

### 4.9 场景 9：审查 Pane — 查看未提交变更

- **给定** 用户在项目状态，项目有未提交变更
- **当** 用户打开审查 Pane
- **则** 默认显示"未提交变更"范围 → 副标题栏显示当前分支、范围选择器(未提交变更)、Staged/Unstaged 计数；内容区列出变更文件及 diff

### 4.10 场景 10：审查 Pane — 切换查看范围

- **给定** 审查 Pane 已打开
- **当** 用户在副标题栏切换范围 → "全部分支变更"
- **则** 内容区刷新显示当前分支 vs base branch 的全部 diff

### 4.11 场景 11：审查 Pane — Stage/Revert 操作

- **给定** 审查 Pane 显示 3 个变更文件
- **当** 用户对某个文件点击 Stage → 对该 hunk 点击 Revert
- **则** 对应文件被 git add；对应 hunk 被 git checkout 还原；内容区刷新

### 4.12 场景 12：审查 Pane — Commit

- **给定** 部分变更已 Stage
- **当** 用户在 commit 消息输入框写消息 → 点击 Commit
- **则** 执行 git commit，内容区刷新；commit 历史中新增一条记录

### 4.13 场景 13：审查 Pane — 查看 Commit 历史

- **给定** 审查 Pane 已打开
- **当** 用户切换到 commit 历史视图
- **则** 显示最近 commit 列表（SHA 短码 + 消息摘要 + 作者 + 时间）；点击某条 commit 展开显示该 commit 的完整 diff

### 4.14 场景 14：浏览器 Pane — 导航操作

- **给定** 浏览器 Pane 已打开
- **当** 用户在 URL 输入框输入 `http://localhost:3000` 并回车
- **则** 浏览器导航到该地址；[←]/[→]/[↻] 正常工作

### 4.15 场景 15：浏览器 Pane — 设备工具栏

- **给定** 浏览器 Pane 已打开
- **当** 用户点击 [⋮] → "显示设备工具栏"
- **则** 浏览器内容区上方出现设备模拟工具栏（设备预设下拉、UA 选择、视口尺寸、旋转按钮、DPR）；选择"iPhone 15 Pro"后网页以对应视口和 UA 渲染

### 4.16 场景 16：终端多实例

- **给定** 已有 1 个终端 Tab
- **当** 用户点击 [+] → 选择"终端"
- **则** 新增第 2 个终端 Tab，独立 shell 进程，工作目录 ~（CHATS）或项目根（项目状态）

### 4.17 场景 17：Tab 溢出滚动

- **给定** AP 已打开 12 个 Tab，标题栏宽度不够
- **当** 部分 Tab 超出可视范围
- **则** 右侧 [>] 按钮可用；点击后 Tab 栏左移，露出隐藏 Tab；左侧 [<] 同时变为可用

### 4.18 场景 18：异常 — 文件不存在

- **给定** 预览区 Tab 中的文件在外部被删除
- **当** 用户切换回该 Tab
- **则** 显示"文件不存在"提示，Tab 标题变灰/倾斜

### 4.19 场景 19：异常 — 大文件

- **给定** 用户尝试预览一个 50MB+ 的文本文件
- **当** 加载判断文件过大
- **则** 显示"文件过大，无法预览"提示，建议外部编辑器打开

### 4.20 场景 20：边界 — 空目录

- **给定** 文件 Pane 打开，根目录下无任何文件或子目录
- **则** Explorer 显示空状态提示

### 4.21 场景 21：边界 — 非 Git 项目

- **给定** 用户在项目状态，但当前项目目录不是 Git 仓库
- **当** 尝试打开审查 Pane
- **则** 显示引导提示"当前目录不是 Git 仓库。运行 `git init` 初始化仓库。"

### 5.3 大按钮规格

- 图标：64×64 px，Pane 类型图标
- 文字：图标正下方，14px，Pane 中文名称
- 按钮整体居中排列，间距 48px
- 点击创建 Pane 实例并以新 Tab 形式加入

### 5.4 各 Pane 副标题栏对照

| Pane | 副标题栏 | 左侧 | 中间 | 右侧 |
|------|---------|------|------|------|
| 浏览器 | 有 | [←][→][↻] | URL 输入框 | [⋮] 菜单 |
| 终端 | 无 | — | — | — |
| 文件 | 有 | 根目录路径（纯文本） | — | Explorer toggle |
| 审查 | 有 | 分支选择器 ▾ | 范围选择器 ▾ | Staged/Unstaged 计数 + StageAll + RevertAll |

## 6. 审查 Pane 详细规格（Codex 对齐）

### 6.1 副标题栏元素

```
┌─ 审查副标题栏 ──────────────────────────────────────────────────┐
│ main ▾  │ 未提交变更 ▾           Staged(3)  Unstaged(5)         │
│         │                         [Stage All]  [Revert All]      │
└────────────────────────────────────────────────────────────────┘
```

- **分支选择器**：下拉列出所有本地分支，当前分支高亮 + 选中
- **范围选择器**（3 项）：
  | 选项 | 说明 |
  |------|------|
  | 未提交变更（默认） | `git diff` + `git diff --cached`，分 Staged/Unstaged |
  | 全部分支变更 | `git diff base-branch...HEAD`，查看分支全量引入 |
  | 上轮变更 | 最近一次 agent turn 产生的文件变更（agent 标记） |
- **Staged/Unstaged 双态 toggle**：切换显示 staged 或 unstaged 文件
- **Stage All / Revert All**：批量操作当前范围的所有变更

### 6.2 内容区结构

```
┌─ 审查内容区 ──────────────────────────────────────────────────┐
│                                                                │
│  ┌─ Commit 消息 ────────────────────────────────────────────┐ │
│  │ [                                ]  [Commit]              │ │
│  └──────────────────────────────────────────────────────────┘ │
│                                                                │
│  变更文件列表:                                                 │
│  ┌─ 📄 src/main/agent/QueryEngine.ts ── [+12 −3] ── [▾] ──┐ │
│  │  @@ -45,7 +45,10 @@                                       │ │
│  │  -  const oldLine                                         │ │
│  │  +  const newLine = await process()                       │ │
│  │  +  const result = validate(newLine)                      │ │
│  │  [Stage hunk] [Revert hunk]                               │ │
│  └───────────────────────────────────────────────────────────┘ │
│  ┌─ 📄 src/renderer/App.tsx ──────────── [+5 −2] ── [▸] ──┐  │
│                                                                │
│  ── Commit 历史 ──────────────────────────────────────────── │
│  ┌─ a3f2b1c feat: add model selector ── 张三 06-09 ── [▸] ┐  │
│  ┌─ 7d1e9f0 fix: session restore bug ── 李四 06-08 ── [▸] ┐  │
└────────────────────────────────────────────────────────────────┘
```

### 6.3 逐块操作

- 每个 diff hunk 下方显示 `[Stage hunk]` `[Revert hunk]` 按钮
- 每个文件行右侧显示 `[Stage file]` `[Revert file]` 按钮
- 操作后内容区实时刷新

### 6.4 Commit 历史

- 默认显示最近 20 条 commit
- 每条显示：短 SHA、消息摘要、作者、时间
- 点击展开完整 diff（该 commit vs 其父 commit）
- 支持加载更早的 commit（滚动到底部触发）

## 8. 安全考量

- 浏览器 Pane：`<webview>` 沙盒隔离，`nodeIntegration: false`，独立 session
- 终端 Pane：不泄露环境变量中的 secret/key
- 文件 Pane：文件系统访问限制在根目录范围内（不超出项目目录）
- 审查 Pane：Git 命令执行限制在项目目录内
- agent 产出内容（HTML/SVG）沙盒渲染，不允许脚本执行
