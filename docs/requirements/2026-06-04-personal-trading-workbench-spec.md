# 个人交易员 AI 工作台产品 SPEC

> **创建日期：** 2026-06-04
> **作者：** xbits / Codex
> **状态：** 草稿

---

## 1. 产品定位

面向个人股票交易员的 AI 工作台。

它不是"自动炒股机器人"，而是帮助交易员完成：

```text
研究 -> 图表分析 -> 策略假设 -> 交易计划 -> 风控检查 -> 手动确认下单 -> 交易日志 -> 复盘
```

核心目标：

> 让交易员把每一笔交易从"临场感觉"变成"有依据、有计划、有风控、有记录、可复盘"的流程。

---

## 2. 核心原则

| 原则 | 说明 |
|---|---|
| 人做最终决策 | AI 可以分析、建议、生成计划，但不能默认自动下单 |
| 证据链优先 | 每个结论都要展示依据：行情、新闻、财报、技术形态、历史数据 |
| 风控强制前置 | 任何真实交易前必须经过仓位、止损、风险收益比检查 |
| Artifact 优先 | 输出不是聊天文本，而是图表、交易计划、复盘报告等可编辑产物 |
| 全流程留痕 | 每笔交易记录分析依据、计划、执行、结果和复盘 |

## 3. 用户场景

### 3.1 个股研究

用户输入：

```text
帮我分析 NVDA 今天是否适合做日内交易
```

系统执行：

1. 拉取行情、K 线、成交量、指数环境。
2. 拉取相关新闻、公告、财报、期权/资金流数据。
3. 生成技术面、基本面、消息面摘要。
4. 输出一个"个股研究 Artifact"。

产物包括：

- 当前价格结构
- 趋势判断
- 支撑 / 压力
- 关键新闻
- 风险点
- 可观察条件

### 3.2 生成交易计划

用户输入：

```text
基于刚才的分析，生成一个低风险日内交易计划
```

系统生成：

```text
交易方向：做多 / 做空 / 观望
入场条件：突破某价格且成交量放大
止损位置：具体价格
止盈位置：第一目标 / 第二目标
仓位建议：基于账户风险
失效条件：跌破某价 / 指数转弱 / 新闻反转
风险收益比：例如 1:2.5
```

注意：系统可以生成计划，但不直接下单。

### 3.3 风控检查

用户准备下单前，系统必须检查：

- 单笔最大亏损是否超限
- 单日亏损是否超限
- 仓位是否过大
- 是否和已有持仓高度相关
- 是否使用杠杆 / 期权 / 高波动标的
- 止损是否明确
- 风险收益比是否合理

如果不满足规则，系统阻止或强提醒。

### 3.4 手动确认下单

用户点击"创建订单"后，系统展示订单预览：

```text
标的：NVDA
方向：Buy
数量：20 shares
订单类型：Limit
限价：$xxx
止损：$xxx
止盈：$xxx
最大亏损：$xxx
账户风险占比：0.8%
```

用户必须手动确认。

真实下单流程：

```text
订单预览 -> 风控通过 -> 用户确认 -> 调券商 API -> 记录日志
```

### 3.5 交易日志

每次交易自动记录：

- 交易时间
- 标的
- 方向
- 入场 / 出场
- 仓位
- 止损 / 止盈
- 交易理由
- AI 分析摘要
- 用户最终决策
- 实际盈亏
- 是否遵守计划

### 3.6 复盘

交易结束后，系统生成复盘：

```text
这笔交易是否符合原计划？
入场是否过早？
止损是否执行？
盈亏比是否合理？
是否受情绪影响？
下次应改进什么？
```

输出复盘 Artifact，可长期积累形成交易员个人数据库。

## 4. 基本 UI

### 4.1 总体布局

```text
┌────────────┬────────────────────┬────────────────────────────┐
│ 左侧导航    │ Conversation        │ Artifact Workspace          │
│            │ AI 交互 / 指令区      │ 图表 / 计划 / 日志 / 复盘      │
└────────────┴────────────────────┴────────────────────────────┘
```

### 4.2 左侧导航

```text
Dashboard      今日市场 / 持仓 / 风险摘要
Watchlist      自选股
Research       个股研究
Charts         图表
Plans          交易计划
Portfolio      持仓与账户
Journal        交易日志
Review         复盘
Settings       数据源 / 券商 / 风控规则
```

### 4.3 Conversation 区

作用：交易员和 AI 的交互区。

显示内容：

- 用户问题
- AI 分析过程摘要
- 工具调用状态
- 风控提醒
- 下单确认
- 任务进度

示例：

```text
用户：分析 TSLA 今天是否有交易机会

AI：
1. 正在读取实时行情
2. 正在分析 1H / 15m / 5m 图表
3. 正在检查相关新闻
4. 已生成研究报告，打开在右侧
```

Conversation 不直接承载复杂图表，只显示摘要和操作入口。

### 4.4 Artifact Workspace

右侧是核心产物区。

支持这些 Artifact：

| Artifact | 内容 |
|---|---|
| Chart | K 线、成交量、均线、支撑压力、交易标记 |
| Research Report | 个股研究报告 |
| Trade Plan | 入场、止损、止盈、仓位、失效条件 |
| Risk Check | 风控检查结果 |
| Order Preview | 下单预览 |
| Journal Entry | 交易记录 |
| Review Report | 复盘报告 |
| Backtest Report | 策略回测结果 |

Artifact 可以 Tab 展示：

```text
[Chart] [Research] [Trade Plan] [Risk] [Journal] [Review]
```

## 5. 核心模块

### 5.1 Agent

负责组织任务流程。

```text
理解用户目标
-> 选择 Skill
-> 拉取上下文
-> 调用工具
-> 生成 Artifact
-> 请求用户确认
-> 写交易日志
-> 生成复盘
```

Agent 不直接下单，必须经过风控和用户确认。

### 5.2 Skills

| Skill | 作用 |
|---|---|
| market_research | 个股研究 |
| technical_analysis | 技术分析 |
| news_analysis | 新闻 / 公告分析 |
| earnings_analysis | 财报分析 |
| trade_plan_generator | 生成交易计划 |
| risk_checker | 风控检查 |
| position_sizing | 仓位计算 |
| journal_writer | 写交易日志 |
| trade_reviewer | 交易复盘 |
| backtest_runner | 回测策略 |

### 5.3 Tools

| Tool 类型 | 示例 |
|---|---|
| 行情工具 | 实时行情、K 线、成交量、指数 |
| 基本面工具 | 财报、估值、公告 |
| 新闻工具 | 新闻、SEC 文件、社媒情绪 |
| 账户工具 | 持仓、余额、订单 |
| 交易工具 | 创建订单、撤单、修改订单 |
| 分析工具 | 技术指标、回测、风险计算 |
| 存储工具 | 交易日志、复盘记录、策略库 |

## 6. 权限设计

| 操作 | 权限 |
|---|---|
| 查询行情 | 自动允许 |
| 查询新闻 / 财报 | 自动允许 |
| 查询持仓 | 用户授权后允许 |
| 生成交易计划 | 自动允许 |
| 创建模拟订单 | 自动允许 |
| 创建真实订单 | 必须用户确认 |
| 修改 / 撤销订单 | 必须用户确认 |
| 使用杠杆 / 期权 | 强确认，可默认禁用 |

---

## 7. MVP 范围

第一版只做：

1. 自选股 + 个股研究
2. 图表 Artifact
3. AI 交易计划生成
4. 风控检查
5. 手动确认下单，或先只做模拟订单
6. 交易日志
7. 交易复盘

暂时不做：

- 全自动交易
- 高频交易
- 复杂期权策略
- 多人协作
- 机构级风控
- 社交跟单

---

## 8. 产品核心闭环

```text
看机会
-> 让 AI 做研究
-> 生成交易计划
-> 风控检查
-> 用户确认执行
-> 自动写日志
-> 收盘后复盘
-> 沉淀个人交易系统
```

一句话总结：

> 这是一个帮助个人交易员建立交易纪律和决策流程的 AI 工作台，而不是替用户赌博的自动交易机器人。
