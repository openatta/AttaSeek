# AttaSeek UI Design

> 主视觉参考：Codex Desktop —— Claude Code Desktop 同样构建于 Codex 的 UI 框架之上，因此优先以 Codex 为源头参考。
> 不是 IDE、不是聊天框 —— 是 **Agent 工作台**。

---

## 1. 整体 Shell

参考 Codex Desktop：系统标题栏只覆盖 Sidebar 宽度。会话区与 AI 输出区各自拥有内联标题栏，功能互不重叠。

```
┌──────┬───────────────────────────────────────────────────────────┐
│  ●●● │  会话标题栏                          [Term] [Diff] [Brow] │  ← 会话区标题栏（靠右 = 打开不同应用的按键）
│ Atta │───────────────────────────────────────────────────────────│
│ Seek │  [Code:api.ts] [Diff] [Terminal]               [⤢] [✕]  │  ← AI 输出区标题栏（TAB 区 + 扩展/隐藏按键）
│      │───────────────────────────────────────────────────────────│
│ Act  │                                                           │
│ Bar  │              Main Canvas（可拖拽面板区）                     │
│ 48px │              AI 输出区内容（消息流 / 工具调用 / 产物）        │
│      │                                                           │
│      │───────────────────────────────────────────────────────────│
│      │  输入区（多行扩展，@ 提及 / / 命令）                         │
└──────┴───────────────────────────────────────────────────────────┘
```

- **系统标题栏**：macOS 红黄绿三按钮位于 Sidebar 左上角，与 Activity Bar 左对齐。标题栏**仅在 Sidebar 宽度区域内**有效（traffic lights 垂直居中对齐 Sidebar 顶部）。Windows/Linux 下窗口控制按钮同样约束在 Sidebar 区域内。
  - Electron 配置：`titleBarStyle: "hiddenInset"`（macOS）/ `titleBarOverlay: true`（Windows/Linux）。
- **会话区标题栏**：位于 Main Canvas 顶部，横跨整个 Canvas 宽度。**只有右侧放置按键**，用于打开不同的功能面板（Terminal、Diff、Browser、Preview 等）。模型/权限/用量指示器不在此处，而在 Conversation 面板内部（见 S5.2）。
- **AI 输出区标题栏**：位于 AI 输出区顶部。左侧 = **TAB 区**，显示当前打开的产物页签（Code、Diff、Preview、Terminal 等），可点击切换、可拖拽排序、可逐个关闭。右侧 = **两个按键**：[⤢] 扩展（该面板全屏展开）和 [✕] 隐藏（折叠该面板）。
- **Activity Bar**：48px 左轨，一级导航
- **Main Canvas**：可拖拽面板区，默认两栏（Sidebar + 主区），主区可自由拆分

核心原则：**极简外壳，内容全在面板里。每个标题栏只做自己区域的事，功能不混杂。**

## 2. Activity Bar

图标 24px 线性，激活态品牌色、非激活态灰度 40%。`Cmd+0~9` 切换。

```
┌──────────┐
│   Logo   │  ← 首页 / 仪表盘
│    +     │  ← 新建会话 / 项目
│  Search  │  ← 全局搜索
│   Auto   │  ← 自动化
│  Plugin  │  ← 插件市场
│   Chat   │  ← 会话列表
│ Projects │  ← 项目列表
│──────────│  ← 分隔线
│ Plugin A │  ← 已安装插件（最多 5 个，溢出收折到 "..."）
│ Plugin B │
│          │
│          │  ← spacer
│          │
│ Settings │  ← 底部对齐
└──────────┘
```

| # | 入口 | 图标 | 快捷键 | 功能 |
|---|------|------|--------|------|
| 0 | Logo | 品牌 Logo | `Cmd+0` | 仪表盘：今日摘要、活跃任务、快捷入口 |
| 1 | + | `+` | `Cmd+N` | 新建浮层：新会话 / 新项目，支持模板 |
| 2 | Search | 搜索 | `Cmd+Shift+F` | 全局搜索：跨会话、项目、知识库 |
| 3 | Automation | 自动化 | `Cmd+3` | 定时任务、后台工作流、触发条件 |
| 4 | Plugin | 插件 | `Cmd+4` | 插件市场：MCP / 工具 / 第三方 Agent |
| 5 | Chat | 对话 | `Cmd+5` | 会话列表（按项目分组，参考 Codex 会话管理） |
| 6 | Projects | 项目 | `Cmd+6` | 项目树、Git 状态、项目内任务 |
| - | 分隔线 | - | - | 以上 = 系统导航，以下 = 已安装插件 |
| P | 插件槽 | 插件图标 | - | 已安装插件快捷入口，按最近使用排序，可拖拽排序 |
| S | Settings | 齿轮 | `Cmd+,` | 全局设置（靠底对齐） |

### 交互

- **单击已激活图标**：Sidebar 折叠/展开
- **Badge**：Chat 未读消息数、Automation 异常任务数
- **右键**：上下文菜单（关闭、快捷键提示）
- **插件区**：拖动排序，右键禁用/卸载，溢出收折到 "..."

## 3. Main Canvas —— 可拖拽面板系统

核心差异化设计。参考 Claude Code Desktop：**所有面板可拖拽重组**，用户自由编排自己的工作区。

### 3.1 面板类型

| 面板 | 说明 |
|------|------|
| **Sidebar** | 上下文面板，内容随 Activity 切换（见 S4） |
| **Conversation** | Agent 对话与控制区（见 S5） |
| **Artifact** | 产物查看/编辑（见 S6） |
| **Terminal** | 集成终端，在应用内运行命令 |
| **Diff** | 代码变更审查，行级接受/拒绝 |
| **Preview** | Web/HTML/图片/PDF 预览 |
| **Browser** | 内嵌浏览器（参考 Codex in-app browser） |

### 3.2 默认布局

新用户首次打开即为以下布局，后续可自由调整：

```
┌──────┬─────────────┬──────────────────────┬────────────────────┐
│ Act  │ Sidebar     │ Conversation         │ Artifact           │
│ Bar  │ 260px       │ 420px                │ flex               │
│      │             │                      │ [Diff] [Preview]   │
│      │             │                      │ [Terminal] ...Tab  │
└──────┴─────────────┴──────────────────────┴────────────────────┘
```

### 3.3 拖拽行为

- **拖拽 Tab** 到面板边缘 - 分栏（上下或左右）
- **拖拽 Tab** 到另一个 Tab 组 - 合并为该组的 Tab
- **拖拽 Tab 脱离** - 独立浮动窗口
- **双击 Tab** - 该面板全屏展开，再双击恢复
- **右键 Tab** - 关闭 / 移动到新窗口 / 固定

### 3.4 预设布局（命令面板切换）

| 预设 | 布局 | 适用场景 |
|------|------|---------|
| 标准 | Sidebar \| Conv \| Artifact | 日常对话 |
| 编程 | Sidebar \| (Conv / Terminal) \| (Artifact / Diff) | 写代码 |
| 审查 | Sidebar \| Diff 全宽 \| Conv 收起为底部条 | 审查 PR |
| 预览 | Sidebar \| Conv \| Preview/Browser 全宽 | 前端开发 |
| 终端 | Sidebar \| Terminal 全宽 \| Conv 收起 | 运维 / 调试 |
| 双会话 | Sidebar \| Conv A \| Conv B | 并行任务 |
| 沉浸 | 单面板全屏 | 专注编码/阅读 |

### 3.5 面板通用交互

- **宽度拖拽**：面板间分隔线可拖拽
- **折叠**：双击分隔线折叠相邻面板
- **全屏**：`Cmd+Shift+Enter` 当前面板全屏
- **关闭**：`Cmd+W` 关闭当前 Tab 或面板
- **分栏**：`Cmd+\` 拆分当前面板

## 4. Sidebar（上下文面板）

260px 默认宽，可拖拽 200~400px。内容由当前 Activity 决定。`Cmd+B` 折叠。

| Activity | Sidebar 内容 |
|----------|-------------|
| 首页 | 今日摘要 + 快捷操作 + 最近项目 |
| Chat | 会话列表（按项目分组、按状态过滤：进行中/已归档；参考 Codex 侧边栏会话管理） |
| Projects | 文件树 + Git 变更文件 + 项目任务 |
| Search | 搜索结果 + 搜索历史 + 知识库分类 |
| Automation | 任务列表（运行中/定时/失败）+ 新建 |
| Plugin | 已安装列表 + 市场浏览 |
| Settings | 设置分类导航 |

### Chat Sidebar 细节（参考 Codex / Claude Code）

```
┌─ Chat ─────────────────────┐
│ 搜索会话...            [+]  │
│────────────────────────────│
│ 筛选: [全部] [进行中] [归档] │
│────────────────────────────│
│ ▼ AttaSeek                │  ← 按项目自动分组
│   ├ 重构 api 模块     2h   │
│   ├ 写测试用例         5h   │
│ ▼ ClawPod                 │
│   ├ 修 bridge 连接 Bug 1d  │
│   └ 更新 proto 定义    3d  │
│ ● 无项目                    │
│   └ 随便聊聊           6d   │
└────────────────────────────┘
```

- Codex Desktop 侧边栏分两区：**Conversations**（无文件夹的自由对话）和 **Projects**（绑定工作目录的项目），AttaSeek 合并为统一 Chat Sidebar
- 会话自动按项目分组（从工作目录或用户指定推断）
- 归档：PR 合并或 7 天无活动自动归档
- 未读蓝点标记
- 右键：重命名 / 归档 / 删除 / 移到项目

## 5. Conversation（Agent 对话与控制区）

### 5.1 消息流

Codex Desktop 的 Conversation 布局 = **Session Header（固定） + 消息流（滚动） + 输入区（固定）**。

```
┌─ Conversation ────────────────────────────────────────────────────┐
│ ✎ 重构 api 模块                     ◉ 82% ████░░  [Opus 4.7 ▾] [Auto ▾]│ ← Session Header（固定，不滚动）
│──────────────────────────────────────────────────────────────────│
│                                                                   │  ← 消息流（可滚动）
│ 用户：重构这个模块                                                  │
│                                                                   │
│ Agent：我计划分三步……                                              │
│   ▸ 展开计划详情                                                   │
│                                                                   │
│ ┌─ 🔧 read src/api.ts ──── [展开 ▸] [↩] ──────────────────────┐ │  ← 工具调用卡片
│ └────────────────────────────────────────────────────────────────┘│
│ ┌─ 🔧 read src/db.ts ───── [展开 ▸] [↩] ──────────────────────┐ │
│ └────────────────────────────────────────────────────────────────┘│
│                                                                   │
│ Agent：已生成 patch                                                │
│ ┌─ 📄 src/api.ts ─── +12 -3 ── [接受] [拒绝] ─────────────────┐ │  ← inline diff 卡片
│ └────────────────────────────────────────────────────────────────┘│
│                       [全部接受 ✓] [全部拒绝 ✕] [逐文件审查 →]     │
│──────────────────────────────────────────────────────────────────│
│ 上下文: 📄api.ts 📄db.ts 🖼️arch.png                               │
│──────────────────────────────────────────────────────────────────│
│ > 你的输入…                                       [停止 ■] [发送 →] │  ← 输入区（固定）
└──────────────────────────────────────────────────────────────────┘
```

### 5.2 会话区标题栏（与 Codex Desktop Session Header 功能一致）

Codex Desktop 的 Session Header 位于 Conversation 面板顶部，**始终固定不随消息滚动**。只有右侧有按键，用于打开不同功能面板。

```
┌─ Session Header ───────────────────────────────────────────────────┐
│ ✎ 重构 api 模块    ◉ 82%  [Opus 4.7 ▾] [Auto ▾]    [▶_] [◉_] [◉_] │
│                                                     Term Diff Brow │
└────────────────────────────────────────────────────────────────────┘
```

#### 布局说明

- **左侧**：会话标题（可编辑）
- **中央**：上下文用量指示器（环形指示器）
- **右侧（控件区）**：模型选择器 + 权限模式切换
- **最右侧（应用按键区）**：打开不同功能面板的快捷按键

#### 控件清单（与 Codex Desktop 对齐）

**1. 会话标题（左侧）**
- 自动生成（从首条用户消息提取）或用户双击编辑
- 编辑态：inline 文本输入框，`Enter` 确认，`Escape` 取消
- 悬停显示编辑图标

**2. 上下文用量指示器（中央，Codex 标志性控件）**
- 圆形环形指示器（circular ring gauge），填充比例 = 已用 / 总量
- 显示百分比文本（如 "82%"）
- 悬停展开详情浮层：
  ```
  ┌─ Context Detail ──────────┐
  │ 已用   3,276,800 tokens    │
  │ 剩余     723,200 tokens    │
  │ 总量   4,000,000 tokens    │
  │───────────────────────────│
  │ 自动压缩阈值: 90%          │
  │ [立即压缩 /compact]        │
  └───────────────────────────┘
  ```
- 超过 80% 环变色为警告色（橙），超过 95% 变为危险色（红）

**3. 模型选择器（右侧，合一控件）**
- 单个下拉按钮，显示当前模型名（如 "Opus 4.7"）
- 展开后面板包含模型列表 + Reasoning Effort（Low/Medium/High）
- 快捷键：`Cmd+Shift+I` 打开模型面板
- 选中后实时生效，**可在会话中途切换**

**4. 权限模式切换（右侧，紧邻模型选择器）**
- Codex Desktop 的三档权限模式，循环切换：Default Review → Auto Review → Full Trust
- 三档说明：
  | 模式 | 行为 |
  |------|------|
  | Default Review | 所有工具调用需用户确认 |
  | Auto Review | 安全操作自动放行，敏感操作（网络/文件写/shell）仍确认 |
  | Full Trust | 所有操作自动执行（Codex 的 YOLO 模式） |
- 快捷键：`Cmd+Shift+M` 循环切换
- 当前模式显示为简短的文本标签（"Ask" / "Auto" / "Trust"）

**5. 应用按键（最右侧）**
- 一排小图标按键，点击在当前 Canvas 中打开对应面板
- 默认显示：Terminal、Diff、Browser（Codex 标志性三件套）
- 可通过 "+" 按键添加更多：Preview、Diagram、Report 等
- 已打开的面板图标高亮，未打开的灰度显示
- 点击已打开的面板图标：跳转到该面板（如已分栏显示则聚焦）
- 与 Activity Bar 的区别：Activity Bar 切换全局 Sidebar 内容；此处是打开 Canvas 内的功能面板

#### 行为规则

- Session Header **固定在 Conversation 面板顶部**，不随消息滚动
- 不是全局标题栏 —— 每个会话独立拥有自己的 Header 状态
- 多面板分栏时，每个 Conversation 面板各自拥有独立的 Session Header

### 5.3 输入区

- **多行自动扩展**，最大 40% 面板高度
- `Enter` 发送，`Shift+Enter` 换行
- `@` 提及：@file / @folder / @agent / @plugin
- `/` 命令：/plan /review /explain /fix /diff
- 附加上下文以 Chip 形式展示在输入框上方（可逐个 x 删除）
- 停止按钮：中断 Agent 执行

### 5.4 Side Chat

Side Chat 是 Claude Code Desktop 在 Codex 基础上的扩展特性。`Cmd+;` 唤起，在当前 Conversation 旁边弹出窄对话框：

```
┌─ Conversation ─────┬─ Side Chat ─────┐
│                     │ > 这个函数是干   │
│ 主任务进行中...      │   什么的？       │
│                     │                 │
│                     │ 它是处理登录     │
│                     │ 状态刷新的...    │
└─────────────────────┴─────────────────┘
```

- **从主会话获取上下文**，但**不写回**主会话
- 用途：任务进行中临时提问、验证想法，不干扰主流程
- `Escape` 关闭

### 5.5 AI 输出区状态指示器（与 Codex Desktop 一致）

仅在 Agent 活跃时出现在消息流顶部，空闲时完全隐藏：

```
┌─ AI Output ──────────────────────────────────────────────────────┐
│ ◉ 正在分析 src/api.ts ...                    [暂停 ■]  [停止 ◼]    │
│──────────────────────────────────────────────────────────────────│
│ Agent：我来重构这个模块的结构，先理解现有代码……                      │
│                                                                   │
│ ... 后续消息流 ...                                                 │
└──────────────────────────────────────────────────────────────────┘
```

- **空闲态**：状态条完全隐藏
- **思考中/执行中**：显示当前操作描述 + 动画指示器
- **等待权限**：显示提示 + 跳转到待确认项的快捷按钮
- **错误**：显示错误摘要 + [重试] [跳过] [复制日志] 按钮

### 5.6 工具调用卡片（Codex 风格）

Codex Desktop 将工具调用渲染为**可折叠的结果卡片**，每张卡片自带撤销按钮：

```
┌─ 🔧 read src/api.ts ───────────────────── [展开 ▸] [↩] ─────────┐
│ Lines: 1-200                                                      │
└──────────────────────────────────────────────────────────────────┘
┌─ ⚙ exec: cargo test ──────────────────── [展开 ▸] [↩] ─────────┐
│ Exit: 0 | 3 tests passed                                          │
└──────────────────────────────────────────────────────────────────┘
```

- **折叠态（默认）**：一行摘要 —— 工具名 + 关键结果
- **展开态**：完整的输入参数 + 输出内容（代码块语法高亮）
- **撤销按钮（↩）**：Codex 的标志性功能 —— 点击回退该工具调用的效果
- **批量撤销**：多选卡片后一次性撤销

### 5.7 权限确认内联（Codex 风格）

权限请求不弹模态框，直接内联在消息流中：

```
⚠️ Execute: npm install @anthropic-ai/sdk

[允许本次]  [允许本会话所有 npm 操作]  [拒绝]  [查看详情]
```

- 三个层级的授权：允许本次（turn-scoped）/ 允许本会话（session-scoped）/ 拒绝
- 待确认项在侧边栏 Chat 项上显示 Badge 数量

### 5.8 Fork（Codex 的会话分支）

Codex Desktop 允许从任意 Agent 消息 fork 出新分支：
- 每条 Agent 消息旁有 Fork 按钮
- 点击后创建新会话，上下文截至该消息为止
- 原会话不受影响，可对比两个分支的结果

### 5.9 消息操作

| 操作 | 方式 |
|------|------|
| 编辑上一条 | `↑`（输入框为空时） |
| 重新生成 | Agent 消息旁 ↻ 按钮 |
| Fork 分支 | Agent 消息旁 Fork 按钮（Codex 特性） |
| 复制代码块 | 一键复制按钮 |
| 引用回复 | 选中文本 → 引用到输入 |
| 收藏 | Agent 消息 → Snippet 库 |

## 6. Artifact（产物面板）

不只预览 —— **可编辑、可保存、可审查、可回滚**。

### 6.1 AI 输出区标题栏

Artifact 面板拥有独立的内联标题栏，左侧 = TAB 区，右侧 = 扩展/隐藏两个按键。

```
┌─ Artifact ────────────────────────────────────────────────────────┐
│ [📄 api.ts ✕] [📊 Diff] [🌐 Preview: index.html] [▶_ Terminal]  [⤢] [✕] │
│──────────────────────────────────────────────────────────────────│
│                                                                   │
│  ... 当前选中 Tab 的内容 ...                                        │
│                                                                   │
└──────────────────────────────────────────────────────────────────┘
```

#### TAB 区（左侧）

- 每个打开的产物页签显示为一个 TAB：
  - **图标 + 名称**（如 📄 api.ts、📊 Diff、🌐 Preview: index.html、▶ Terminal）
  - 名称过长时截断（保留首尾，中间 "..."）
  - 每个 TAB 右侧有 **✕ 关闭按钮**
  - 当前选中 TAB 高亮（品牌色下划线或背景色差）
- **点击 TAB**：切换到该产物
- **拖拽 TAB**：可排序，也可拖出到新面板（触发分栏）
- **右键 TAB**：关闭 / 关闭其他 / 关闭右侧 / 移动到新面板
- **TAB 来源**：
  - Agent 工具调用自动产出（代码文件、Diff、测试报告等）
  - 用户手动打开（Sidebar 文件树双击、全局搜索打开）
  - Session Header 应用按键触发（Terminal、Browser 等）
  - Side Chat 产出（用户选择"发送到主会话"）
  - 外部拖入文件

#### 按键区（右侧）

只有**两个按键**：

| 按键 | 图标 | 功能 |
|------|------|------|
| **扩展** | ⤢ | 当前 Artifact 面板全屏展开（撑满整个 Canvas，再按恢复） |
| **隐藏** | ✕ | 折叠/关闭当前 Artifact 面板（TAB 状态保留，展开即恢复） |

- 两个按键紧凑排列在标题栏最右侧
- 与 macOS 红绿灯逻辑呼应：扩展 = 全屏（绿色），隐藏 = 关闭面板（红色）
- 快捷键：`Cmd+Shift+Enter` 扩展/恢复，`Cmd+W` 隐藏面板

## 11. 视觉设计

### 11.1 风格参考

- **基调**：以 Codex Desktop 的暗色极简为基调，辅以 Claude Code Desktop 的功能密度（Claude Code Desktop 本身构建于 Codex UI 框架之上，两者同源）
- **默认暗色**，支持亮色 / 跟随系统
- **低对比度分隔**：面板间用 1px 边框或微妙色差区分，避免粗重分割线
- **强调色**：品牌主色用于焦点、Badge、激活态；语义色用于错误/警告/成功

### 11.2 字体

| 用途 | 字体 | 大小 |
|------|------|------|
| UI | 系统原生（SF Pro / Segoe UI） | 13px |
| 对话 | 系统原生 | 15px |
| 代码 | JetBrains Mono / SF Mono | 14px |

### 11.3 图标

- Activity Bar：24px 线性
- Sidebar / Tab：16px
- 统一 Phosphor 或 Lucide，不混用

### 11.4 密度

- 默认舒适：行高 1.5、间距 8px
- 可选紧凑：行高 1.3、间距 4px

### 11.5 动画

| 动作 | 时长 | 缓动 |
|------|------|------|
| 面板切换 | 150ms | ease-out |
| 消息出现 | 200ms | ease-out + 微上移 |
| 工具调用展开 | 300ms | 渐进 |
| 浮层 | 100ms | fade + scale |
| 全屏切换 | 250ms | ease-in-out |
| 面板拖拽吸附 | 200ms | ease-out |

## 12. 交互设计规则

1. **任何面板都可折叠** — 折叠不销毁内容，展开即恢复
2. **操作可撤销** — 关闭 Tab / 删除消息需确认或支持 undo；工具调用支持逐条撤销（Codex 特性）
3. **键盘可达** — 所有功能在命令面板和快捷键中可达
4. **右键有菜单** — 所有列表项、Tab、消息、图标支持右键
5. **拖动可重组** — Tab 和面板可拖拽排序/分栏/独立窗口
6. **焦点明确** — 当前活跃面板有 2px 品牌色边框指示器
7. **加载有骨架** — 首次加载骨架屏，局部刷新 shimmer
