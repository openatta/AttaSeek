# Test Project

This is a **test project** for AttaSeek E2E testing.

## Features

- TypeScript support
- CSS styling
- Utility functions

## Getting Started

```bash
npm install
npm run dev
```

## API

| Function | Description |
|----------|-------------|
| `formatDate` | Format a date to YYYY-MM-DD |
| `debounce` | Debounce a function call |
| `clamp` | Clamp a value between min and max |
